# Kushal Pathak — Portfolio

Personal portfolio website showcasing my experience, projects, skills, and contact information.

## Live Website

https://kushalpathak.com.np

## Built With

* Vite
* React
* JavaScript
* CSS

## Local Development

```bash
git clone https://github.com/Kushal-Pathak/kushal-pathak.github.io.git
cd kushal-pathak.github.io
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

The website is automatically built and deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the `main` branch.
